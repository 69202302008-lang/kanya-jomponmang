สร้างเว็บไซต์ออนไลน์ฟรีด้วย GitHub

  1. สร้าง Repository ใหม่: ไปที่ GitHub.com แล้วกด New Repository ตั้งชื่อเช่น my-portfolio
  2. อัปโหลดไฟล์: ตั้งชื่อไฟล์นี้ว่า index.html แล้วลากไฟล์ลงใน Repository
  3. เปิดใช้งาน Pages: ไปที่เมนู Settings → Pages
  4. เลือก Branch: ใต้หัวข้อ Build and deployment ให้เลือก Branch เป็น main หรือ master แล้วกด Save
  5. เรียบร้อย! รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://username.github.io/my-portfolio
